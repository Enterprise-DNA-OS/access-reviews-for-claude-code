# Why these records do not need another application

The weekly work is deciding who should retain access, identifying late reviews, following removals and producing evidence. Claude Code, Codex, OpenCode or Cursor use the same local commands against a database. Read-only HTML snapshots show the work and branded documents support a review meeting.

A screen adds individual reviewer sign-in, mobile access, live assignment notifications and concurrent browsing. This base supplies none of those. Local PGlite has one writer process. It has no offline sync, connector polling, drag-and-drop workflow or automatic revocation. HTML output is a dated snapshot, not a live access control.

The database stores operator assertions, not authenticated approvals. Team deployment needs authenticated identities, authorization and private evidence storage.
